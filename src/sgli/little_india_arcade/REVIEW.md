# Little India Arcade

Models all twelve supplied parts: Serangoon strip 176326900 and Campbell Lane 176326798, 176326872, 176326923, 176326965, 176326698, 176326731, 176326759, 176326784, 176326792, 176326803, 176326811. Each has a sheltered five-foot way, plaster pilasters/capitals, string courses and dentils, blue/teal louvred shutters with individual slats, arched transoms, terracotta pitched roofs and ridge/tile courses. Campbell Lane gables have raised cornice edges and keystones. Blank warm shop panels, no text.

The initial repeated perpendicular gables have been replaced using the newly arrived top/reference views; occasional front pediments remain as photographic façade ornament. The current footprint set is narrower and less complete than the three-block, 26-shophouse complex described in URA's 1996 conservation award PDF (https://www.ura.gov.sg/-/media/Corporate/Get-Involved/Conserve-Built-Heritage/AHA/1996/AHA-1996---Little-India-Arcade.pdf). Do not infer that all Campbell Lane parcels belong to the Arcade solely from this dataset's repeated `name` field. OSM API context (`/workspace/li_photo_refs/little_india_arcade/osm_context.xml`, fetched 2026-11-01; https://www.openstreetmap.org/api/0.6/map?bbox=103.8512,1.3051,103.8524,1.3062) resolves the three-block layout: seven Serangoon parcels (42–54), eleven Campbell parcels (2–22), eight Hastings parcels (1–8) = 26. This matches URA's count but remains a geographic inference, not verified ownership records.
